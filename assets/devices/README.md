# Device images

Product renders of Nothing and CMF devices. They are copyright © Nothing Technology Limited
and are included only so the app can show which device is connected. "Nothing" and "CMF"
are trademarks of Nothing Technology Limited. This project is not affiliated with Nothing.

Every supported model has an image here; unknown devices fall back to a built-in vector drawing.
Any `<model code>.png` placed in `~/Library/Application Support/NothingX/images/` overrides these.
